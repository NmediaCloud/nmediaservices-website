Backup tools tend to arrive with a dependency tree. This one arrives with none. It is a mirror-backup utility for Windows with a Tkinter GUI and a full CLI, written entirely against the Python standard library, and that restriction is the whole design rather than an accident of scope.

01Why zero dependencies matters

No pip install. No virtualenv. No supply chain to audit or to be compromised. It runs on a locked-down corporate machine, an air-gapped machine, or a fresh Windows install with nothing on it but Python. Everything it uses, tkinter, pathlib, hashlib, argparse, json, logging and shutil, ships with Python and is cross-platform, so the same single file runs unchanged on macOS and Linux.

"The machines that most need a backup tool are often the ones you are least allowed to install software on."

02What it does

CapabilityBehaviour
Mirror a folder treeCopies only what changed, to a second location
Deep verifyHashes the copy, so corruption is detected rather than assumed away
Dry runReports exactly what would be copied, replaced and deleted, before anything happens
Delete extrasOptional, making the destination a true mirror rather than an accumulating pile
ExclusionsJunk and chosen formats stay out: thumbnails, caches, whatever you name
Named profilesDefine a source and destination pair once, then run it by name from the GUI or the CLI
Index, plan, historyWritten to disk, so a run is inspectable afterwards and repeatable

03The honest warning

A true mirror deletes. --delete-extra makes the destination match the source, which means removing things the source no longer has. That is the feature, and it is also the way to lose data if you point it at the wrong pair. Dry-run an unfamiliar pair first, read what it reports, and keep a second copy of anything you cannot lose. The tool will tell you what it is about to do; it will not decide for you whether you meant it.

04Running it

The GUI launches from the same file as the CLI. A profile is a named source and destination pair, so a routine backup becomes one command or one click, and an unfamiliar one stays a deliberate act with a dry run in front of it. Configuration lives in two local JSON files that hold real drive paths and are deliberately never published.
